# MAX — навигатор досуга и активного отдыха

Чат-бот для MAX, который помогает пользователю быстро найти места для досуга и спорта рядом с собой.

Бот определяет местоположение пользователя через геолокацию или введённый адрес, позволяет выбрать интересующую категорию и получает подходящие места через API 2GIS. Пользователь может настроить радиус поиска и отмечать места, которые уже посещал.

# 1. Назначение решения

Основная задача решения — сократить путь пользователя от желания найти, чем заняться, до конкретного подходящего места рядом с ним.

Вместо самостоятельного поиска по нескольким сервисам пользователь проходит основной сценарий непосредственно в MAX:

1. Открывает чат-бота;
2. Передаёт геолокацию или вводит адрес;
3. Выбирает направление;
4. Выбирает категорию;
5. Получает подходящее место рядом;
6. При необходимости отмечает место как посещённое;
7. Может продолжить поиск или изменить параметры.


# 2. Основной пользовательский сценарий

После запуска бота пользователь видит главное меню:

* **Куда пойти**
* **Посещенные места**
* **Настройки**

При нажатии кнопки "Куда пойти", Бот предлагает отправить или ввести вручную адрес.

После ввода адреса, бот предлагает направления и категории.

## Доступные категории досуга

* Кино
* Театры и концерты
* Парки
* Аттракционы
* Квесты

## Доступные категории спорта и активного отдыха

* Фитнес-клубы
* Бассейны
* Спортивные секции
* Спортивные школы
* Стадионы
* Скейт-парки
* Роллердромы
* Катки

После получения результата, Пользователь может отметить место как "Я был здесь" и поставить ему оценку.


# 3. Хранение данных

Для хранения данных используется SQLite

## База данных

По умолчанию:

./data/bot.db

В ней хранятся:

### Пользователи

* ID пользователя MAX;
* username;
* имя;
* выбранный радиус;
* время создания;
* время последней активности.

### Геолокация

Для пользователя хранится последняя известная геолокация.

### История поиска

* категория;
* координаты;
* радиус;
* время поиска.

### Места

Для пользователя сохраняются места, которые бот уже показывал или которые пользователь отметил как посещённые.

# 4. Внешние сервисы и интеграции

## 2GIS API

Используется для:

* поиска объектов рядом с координатами пользователя;
* фильтрации по категориям;
* сортировки результатов по расстоянию;
* геокодирования введённого пользователем адреса.

# 5. Переменные окружения

## Файл окружения

Для запуска необходимо создать файл в директории приложения:

.env

на основе:

.env.example

Заполнив переменные.

## Описание переменных

| Переменная   | Назначение                          | Пример               |
| ------------ | ----------------------------------- | -------------------- |
| `BOT_TOKEN`  | Токен MAX-бота                      | `your_max_bot_token` |
| `TWOGIS_KEY` | API-ключ 2GIS                       | `your_2gis_api_key`  |
| `DB_PATH`    | Путь к SQLite                       | `./data/bot.db`      |
| `LOG_PATH`   | Путь к файлу логов                  | `./logs/bot.log`     |
| `LOG_LEVEL`  | Уровень логирования                 | `info`               |
| `LOG_SALT`   | Псевдонимизация ID в логах          | `change-me`          |

# 6. Зависимости

Основные зависимости проекта:
